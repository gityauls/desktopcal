DesktopCal 개인정보처리방침

시행일 2026년 10월 12일

1. 한 줄 요약

DesktopCal 은 내 PC 에서만 동작하는 달력 프로그램입니다. 개발자가 운영하는 서버가 없고, 개발자는 사용자의 어떤 정보도 받지 않습니다. 내 일정·할 일·메모와 구글 계정 정보는 내 PC 와 내 구글 계정 사이에서만 오갑니다. 사용 기록이나 통계를 모으지 않고, 광고도 없습니다.

2. 구글 계정 연결 시 사용하는 권한

구글 연결은 사용자가 원할 때만 하며, 사용자가 자기 구글 계정에서 직접 만든 인증 파일(OAuth 클라이언트)로 이루어집니다. 구글에 연결하지 않아도 달력·D-Day·기념일·할 일·메모는 이 PC 안에서 그대로 쓸 수 있습니다(다른 PC·휴대폰과 맞추는 것만 빠집니다).

구글 캘린더 https://www.googleapis.com/auth/calendar
캘린더 목록과 일정을 읽어 달력에 보여 주고, DesktopCal 에서 추가·수정·삭제한 일정을 내 구글 캘린더에 반영합니다. D-Day·기념일·메모·할 일 추가 정보를 다른 PC 와 맞추기 위한 전용 캘린더(4장 참고)를 만들고 그 안에 저장합니다.
구글 할 일 https://www.googleapis.com/auth/tasks
구글 할 일(Google Tasks)의 목록과 할 일(제목·설명·날짜·완료 여부)을 읽고, DesktopCal 에서 만들거나 고친 할 일을 반영합니다. 휴대폰의 Google Tasks 와 같은 할 일을 보게 하려는 것입니다.
  • 로그인할 때 구글 권한 화면에서 '구글 할 일'을 체크하지 않으면 할 일 연동만 빠지고, 캘린더 연결은 그대로 됩니다.
  • DesktopCal 의 구글 API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다. 구글에서 받은 정보는 위에 적은 기능에만 쓰고, 광고·판매·다른 목적의 분석에 쓰지 않으며, 다른 곳으로 보내지 않고, 사람이 읽지 않습니다.

3. 이 PC 에 저장되는 것

  • 설정, 일정 사본, D-Day, 기념일과 그 백업, 할 일, 메모, 구글 로그인 토큰, 티커에 넣은 API 키, 오류 기록(로그)은 내 PC 의 %APPDATA%\DesktopCal 폴더에만 저장됩니다.
  • 구글 로그인 토큰과 API 키는 화면과 오류 기록에 내보내지 않습니다. API 키는 그 키를 발급한 서비스에 정보를 요청할 때만 쓰입니다.
  • 개발자는 이 폴더의 정보에 접근할 수 없습니다.

4. 내 구글 계정에 저장되는 것

  • DesktopCal 에서 넣은 일정은 내가 고른 구글 캘린더에, 할 일은 구글 할 일에 저장됩니다.
  • 다른 PC 와 맞추기 위해 내 구글 캘린더 안에 다음 전용 캘린더를 만듭니다: DesktopCal D-Day, DesktopCal 기념일(기념일 규칙과 백업), DesktopCal 메모, DesktopCal 할 일(구글 할 일에 없는 시간·기한·색·반복 같은 추가 정보).
  • 이 캘린더들은 내 구글 계정 안에만 있으며, 구글 캘린더 웹·앱에서 보거나 지울 수 있습니다.

5. 티커(달력 아래 글자 띠)가 접속하는 곳

티커는 처음에는 꺼져 있습니다. 켜면 날씨·미세먼지·뉴스·시세·환율 같은 공개 정보를 아래 서비스에서 이 PC 가 직접 받아 옵니다.

  • 보내는 것은 요청에 꼭 필요한 값뿐입니다. 예를 들어 설정에서 고른 지역(행정구역 코드나 그 지역 중심 좌표), 내가 넣은 API 키, 내가 고른 종목입니다. 일정·할 일·메모와 구글 계정 정보는 보내지 않습니다.
  • 주요 접속처: Open-Meteo(날씨·대기질), 공공데이터포털(기상청·에어코리아 등, 키를 넣었을 때), 한국수출입은행·Frankfurter(환율), 업비트(가상자산 시세), OpenDART(공시, 키를 넣었을 때), 영화진흥위원회 KOBIS(박스오피스, 키를 넣었을 때), 키움증권(주식 시세, 키를 넣었을 때), 언론사 RSS(뉴스 제목), DesktopCal 중계 파일(gityauls.github.io/desktopcal-feed — 공개 정보를 미리 모아 둔 파일, GitHub Pages).
  • 보통의 웹 접속처럼, 접속한 서비스에는 이 PC 의 인터넷 주소(IP)가 남을 수 있으며 그 정보는 각 서비스의 방침을 따릅니다.
  • 티커의 줄을 누르면 그 내용의 사이트(뉴스 기사 등)가 기본 브라우저로 열립니다.
  • 티커를 끄면 위 서비스에 접속하지 않습니다.

6. 연결 끊기와 지우기

  • DesktopCal 설정에서 구글 동기화를 끄면 더 이상 구글과 주고받지 않습니다.
  • 구글 계정 → 보안 → 서드 파티 액세스에서 DesktopCal 의 권한을 언제든지 해제할 수 있습니다.
  • 4장의 전용 캘린더는 구글 캘린더 설정에서 지울 수 있습니다.
  • %APPDATA%\DesktopCal 폴더를 지우면 이 PC 에 저장된 정보가 모두 지워집니다.
