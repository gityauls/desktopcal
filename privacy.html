DesktopCal 개인정보처리방침

시행일 2026년 10월 3일

1. 한 줄 요약

DesktopCal 은 내 PC 에서만 동작합니다. 내 일정과 구글 계정 정보는 내 PC 와 내 구글 계정 사이에서만 오가며, 개발자를 포함한 다른 누구에게도, 어떤 서버로도 보내지 않습니다.

2. 구글 캘린더 연결 시 사용하는 정보

  • 사용하는 범위: Google Calendar API (https://www.googleapis.com/auth/calendar)
  • 하는 일: 내 구글 캘린더의 일정·캘린더 목록을 읽어 달력에 보여 주고, 내가 DesktopCal 에서 추가·수정·삭제한 일정과 D-Day·기념일을 내 구글 캘린더에 반영합니다.
  • 구글 연결은 사용자가 자기 구글 계정에서 직접 만든 인증 파일(OAuth 클라이언트)로 이루어집니다.
  • DesktopCal 의 구글 API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다. 받은 정보를 광고, 판매, 다른 목적의 분석에 쓰지 않으며 사람이 읽지 않습니다.

3. 저장 위치

  • 설정, 일정 사본, D-Day, 기념일, 구글 로그인 토큰은 내 PC 의 %APPDATA%\DesktopCal 폴더에만 저장됩니다.
  • D-Day·기념일은 다른 PC 와 맞추기 위해 내 구글 캘린더 안의 전용 캘린더(DesktopCal D-Day, DesktopCal 기념일)에도 저장됩니다.
  • 개발자는 이 정보에 접근할 수 없습니다.

4. 연결 끊기와 삭제

  • DesktopCal 설정에서 구글 동기화를 끄면 더 이상 구글과 주고받지 않습니다.
  • 구글 계정 → 보안 → 서드 파티 액세스에서 DesktopCal 의 권한을 언제든지 해제할 수 있습니다.
  • %APPDATA%\DesktopCal 폴더를 지우면 이 PC 에 저장된 정보가 모두 지워집니다.

5. 문의

궁금한 점은 GitHub 또는 DesktopCal 을 전해 준 사람에게 문의해 주세요. 이 방침이 바뀌면 이 페이지에 시행일과 함께 알립니다.
